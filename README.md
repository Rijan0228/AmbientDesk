# AmbientDesk

A customizable ambient dashboard for spare laptops, tablets,
second monitors, and desktop displays.

## Features

- Live digital clock
- Weather information
- Monthly calendar
- Focus timer
- Music player
- Audio visualizer
- Matrix animation
- Multiple visual themes
- Fullscreen display mode
- Customizable widget visibility
- Theme sharing through URL
- Responsive layout

## Themes

- Cyberpunk
- Cozy
- Matrix
- Minimal

## Technologies

- HTML
- CSS
- JavaScript ES Modules
- Canvas API
- Web Audio API
- Open-Meteo Weather API
- Local Storage

## Running locally

Because AmbientDesk uses JavaScript modules, open it through a local
development server rather than directly opening index.html.

For example, with VS Code, use the Live Server extension.

## GitHub Pages

1. Upload the project files to a GitHub repository.
2. Open repository Settings.
3. Select Pages.
4. Choose the main branch and root folder.
5. Save and wait for deployment.

## Privacy

Weather location is requested only when needed.

User settings are stored locally in the browser.

The planned music-upload feature will use local device files.
Audio files will not be uploaded to a server.
